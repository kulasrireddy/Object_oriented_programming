# Object-Oriented Programming in Python

A structured collection of **Object-Oriented Programming (OOP) concepts implemented in Python**. This repository contains practical examples and Jupyter notebooks created while learning and practicing core OOP concepts.

The goal of this repository is to build a strong understanding of Python OOP fundamentals through simple, practical, and easy-to-understand examples.

## 📚 Topics Covered

### 1. Classes and Objects

Introduction to classes, objects, constructors, attributes, and methods.

**File:** `Class_Objects.ipynb`

### 2. Inheritance

#### Single Inheritance

A child class inherits properties and methods from a single parent class.

**File:** `Single Inheritance.ipynb`

#### Multiple Inheritance

A child class inherits from multiple parent classes.

**File:** `Multiple_Inheritance.ipynb`

#### Multilevel Inheritance

Inheritance implemented across multiple levels of a class hierarchy.

**File:** `Multi-Level_Inheritance.ipynb`

#### Hierarchical Inheritance

Multiple child classes inherit from the same parent class.

**File:** `Hierarchical_Inheritance.ipynb`

### 3. Polymorphism

Understanding how the same method or interface can behave differently depending on the object.

**File:** `Polymorphism.ipynb`

### 4. Encapsulation

Understanding data hiding, private attributes, and controlled access to class data using methods.

**File:** `Encapsulation.ipynb`

### 5. Abstraction

Understanding abstract classes and abstract methods using Python's `ABC` module.

**File:** `Abstraction.ipynb`

## 💡 Key OOP Concepts

| Concept           | Purpose                                                            |
| ----------------- | ------------------------------------------------------------------ |
| **Class**         | Blueprint for creating objects                                     |
| **Object**        | Instance of a class                                                |
| **Encapsulation** | Bundling data and methods and controlling access                   |
| **Inheritance**   | Reusing properties and methods from another class                  |
| **Polymorphism**  | Same interface with different implementations                      |
| **Abstraction**   | Hiding implementation details and exposing essential functionality |
